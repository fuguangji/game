# 術式武器

這個遊戲只有七把術式武器（沒有普通武器）。新手從「塵流懸液」開始（免費），其他六把在商城「槍械」分頁購買。每把除了普通攻擊，還有技能與術式場。

**出戰規則**：最多同時裝備 2 把（在「備戰」選擇），可用 Q、滾輪或 1 / 2 切換；術式與冷卻、能量是共用的，熱量等專屬資源則只屬於該武器。
下面的對照表由程式內的註冊表自動產生，數字就是實際數值；想調整請改 `js/techniques/` 裡對應的檔案。

## 操作

畫面下方只顯示「目前選定」的那一格（普通攻擊或某個技能），不會擠成一排按鈕。

| 輸入 | 作用 |
|---|---|
| 滑鼠滾輪 | 切換選定的格子：普通攻擊 ↔ 技能 1 ↔ 技能 2 … |
| 滑鼠左鍵 | 發動選定的格子（選普通攻擊時可按住連射；選技能時按一下發動一次，蓄力類技能再按一次釋放） |
| Z X C V B N | 不用切換，直接施放第 1~6 個技能 |
| 空白鍵／SUPER | 展開第 1 個術式場（需要大招蓄滿；用普通攻擊與技能造成傷害來蓄能） |
| E | 展開第 2 個術式場（目前只有未雨鎩有；同樣需要大招蓄滿） |
| 數字鍵 1~9 | 塵流懸圖展開時，控制 9 層同心圓（Shift＋數字＝引爆該層） |
| Q、數字鍵 1 / 2 | 切換出戰的兩把武器 |
| 手機：◀ ▶ | 切換選定的格子（也可以點下面的小圓點直接選） |
| 手機：右半邊拖曳後放開 | 發動選定的格子（也可以直接點選定的那一格） |
| 手機：塵流懸圖面板 | 點 1~9 切換該層旋轉；先點「爆破」再點數字＝引爆該層 |

## 資源與名詞（對照遊戲內的實作）

- **能量**：技能的消耗，上限 100，每秒回復 14。訓練場開啟「無限彈藥／大招」時能量與冷卻都不限。
- **熱量**（青羽鎩專用）：用衰變、托克馬克累積，轉能與中子射線流消耗；不使用時每秒緩慢下降。
- **術式熔斷**：無法施放術式與展開術式場（普通攻擊、移動、衝刺都不受影響）。
- **靈魂熔斷**：無法操縱，不能移動、不能攻擊。**Boss 免疫靈魂熔斷**（改為術式熔斷同樣時間），Boss 被術式熔斷時持續時間減半。
- **熔斷無效**（汽焊）：期間熔斷與靈魂熔斷都施加不上去。
- **術式反噬**：施放技能時對自己造成的傷害（最大生命值的比例）。**不會致死**，最少留 1 點生命。「代價」欄的生命消耗則是另外扣的，血量不足時不能施放。
- **次術式場**：不需要大招蓄能的圓形範圍效果（日全蝕、二極體、瑟颯峽村…）。
- **1 公尺** = 48 像素。
- 敵人身上的效果會在頭上顯示彩色虛線圈；你身上的效果會顯示在角色周圍與 HUD。

## 詮釋說明（原設定在遊戲裡無法一字不差實現，這裡是我的取捨）

- 「術式熔斷／靈魂熔斷」「術式反噬」是這套系統的核心名詞，已對應成上面的規則；原設定中的「靈魂」「術式」等沒有直接對應的物件，皆以「無法行動／無法攻擊／受傷」呈現。
- **能量**對敵人沒有意義，所以敵人的「能量流失」改成持續失去生命（並把流失量補給你一些能量）。
- **時柳**：預支能量＝能量滿並多出 100、10 秒內技能免費；「抽走對方能量」＝敵人被熔斷並損血、你回血；時間到後昏迷 4 秒。
- **負片**：「狀態逆流」＝能量回滿、生命回到 5 秒前的水準（不會比現在低）、清除負面狀態；代價 30 秒術式熔斷，依原設定不縮短。
- **鏡川殘卷**：映射＝把周圍的敵方子彈變成你的子彈（威力減半）；2 分鐘熔斷也依原設定。
- **鳶尾天平非穩態**：反射的傷害不致死；沒有目標時反噬由自己承受。
- **朗、爐心熔毀**：「範圍內所有人」只作用在敵人身上，施術者不受影響（爐心熔毀的 2000% 反噬以「每秒約 20% 最大生命」呈現）。
- **霜雪風域**：敵人受到與造成的傷害幾乎為零，反噬照常；「位置不可讀取」＝場內敵人看不見你，只會追假位置。
- **塵流懸圖**：只旋轉敵人與敵方子彈，不會轉動施術者。
- **竹式神**：沿用既有的砲塔機制，用你手上的竹針射擊。

## 新增一套術式

1. `js/game/weapons.js` 的 `#definitions` 末尾新增一把同名武器（`id` 等於它在陣列的位置），再到 `js/game/progress.js` 的 `WPR` 補價格（貨幣表長度會自動跟著）。所有武器都必須註冊術式，測試會檢查。
2. 在 `js/techniques/` 新增檔案（照 `qingyu.js` 的格式），呼叫 `registerTechnique({ weapon, color, skills, domains })`，再到 `js/techniques/index.js` 加一行 `import`。
3. 技能與術式場都用 `js/game/techniques.js` 的工具箱組合：

| 工具 | 用途 |
|---|---|
| `aoe(x, y, r, dmg, { kb, fx, burn, tag, walls })` | 圓形範圍傷害；`fx` 是對敵人施加的效果清單，如 `[["seal", { duration: 5 }]]` |
| `cone(x, y, 角度, 距離, 弧度, dmg, { cutBullets })` | 扇形，可同時擊落敵方子彈 |
| `beam(x, y, 角度, 長度, 寬度, dmg, { pierceWalls, first, fx })` | 瞬間命中的射線 |
| `field({ x, y, r, t, col, every, dmg, each, tick, follow })` | 持續範圍場（次術式場、燃燒地面） |
| `domain({ x, y, r, t, color, update, draw, lockSkills, blind, confine, onDigit })` | 展開術式場（同時只有一個） |
| `addFx({ t, update, draw, end, skill, release })` | 任意持續效果；寫 `skill` 與 `release` 就能做「再按一次釋放」 |
| `hitEnemy(e, dmg)`、`enemiesIn`、`bulletsIn`、`nearestEnemy`、`moveAlong`、`healPlayer`、`ring`、`strokeRing` | 其他輔助 |

玩家身上的效果加在 `js/game/status-effects.js` 的 `STATUS`，敵人身上的加在 `js/game/enemy-effects.js` 的 `ENEMY_FX`（見 README）。

技能的欄位：`name`、`cost`（數字，或 `(ctx) => 數字`）、`cd`、`backlash`（反噬，最大生命比例）、`hpCost`（生命代價）、`desc`（必填）、`cast(ctx)`。
`ctx` 有 `p`（玩家）、`aim`（瞄準角度）、`x, y`（瞄準點）、`dist`、`target`（瞄準點附近的敵人）。

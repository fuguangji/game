- `ftxt()` 原本是空函式，現在會將浮動文字寫入 `fxs` 特效佇列。

- 為本檔案中的具名函式與可辨識的具名箭頭函式補上用途註解；少數原本已有相鄰註解的宣告保留原註解，避免重複。

- 電荷命中、電荷引爆、暈眩等程式碼會呼叫 `ftxt(...)`，舊版空函式會使這些文字提示完全不顯示。
- 舊版隱藏控制元件 `#aa` 與 `#bW` 仍留在 HTML；本次未刪除，因為尚未確認是否有相容或事件處理用途。
- 本版未發現先前提到的 `SPELLS` 資料表；不沿用舊 PR 對術式數量的判斷。
- 狀態機圖、教學流程與主要 UI 的註解已納入本次檢視範圍，但尚未完成實際瀏覽器操作、手機觸控及完整逐條遊戲平衡測試。

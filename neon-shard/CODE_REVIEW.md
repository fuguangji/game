# NEON SHARD 程式碼審查紀錄

## 本次修改

- 補上所有具名 `function` 宣告的用途註解，並補充具名箭頭函式 helper 的說明；小型匿名回呼仍保留在原本的呼叫位置，避免為了註解而重構事件流程。
- 修正檔案開頭的架構註解：原文寫「10 套術式」，但目前 `SPELLS` 資料表有 20 個術式定義。現在改為以 `SPELLS.length` 為準，避免日後增刪術式時註解再次過期。
- 修正 `ftxt()` 原本的空函式問題。該函式有多個呼叫端（例如電荷引爆與暈眩提示），但原實作完全不做事；現在會建立短暫浮動文字特效，繪圖迴圈也新增對應的 `txt` 特效分支。

## 發現但未直接移除的舊 UI

### 1. 舊版自動瞄準按鈕 `#aa`

- HTML 內的按鈕以 `display:none!important` 隱藏。
- `setAA()` 仍會更新它的文字與狀態 class；真正可操作的模式切換位於暫停介面的 `#aa0`、`#aa1`、`#aa2`。
- 判定：這是殘留的舊介面同步程式，不是目前主要的自動瞄準入口。建議確認不再需要相容後，移除隱藏按鈕與同步程式。

### 2. 舊版武器切換按鈕 `#bW`

- CSS 以 `display:none!important` 強制隱藏。
- JavaScript 仍會更新按鈕文字、切換 `on` class，並註冊 `pointerdown` 事件；因元素不可見，這段舊 UI 互動無法由玩家正常觸發。
- 判定：它與目前透過裝備欄位操作切換術式的流程並存，屬於疑似未清理的舊控制。暫時保留，避免未確認手機操作設計前刪掉可能仍有用途的邏輯。

## 檢查限制

- 本次是靜態原始碼審查，沒有在真實瀏覽器中完整遊玩、測量效能或測試手機觸控。
- 新增的浮動文字效果尚需實際驗證不同畫面縮放、長文字、特效密集時的顯示表現。
- 建議下一輪用瀏覽器測試：首次教學、電荷引爆、暈眩提示、術式切換、暫停／恢復、手機觸控，以及舊存檔載入。

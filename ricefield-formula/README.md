# 稻香方程式：空天黎明 (V1 原型)

直接用瀏覽器開啟 `index.html` 即可遊玩（純 HTML5 + 原生 JS + Canvas，無需伺服器/網路；進度存於 localStorage）。

## 操作
- 工作台：左鍵放置(可拖曳連放)／右鍵拆除／滾輪縮放／中鍵或 Space+左鍵平移／R 旋轉／F 鏡像／Ctrl+Z/Y／Space(不拖曳時放開)＝試飛
- 觸控：點格放置、長按拆除、雙指縮放平移；飛行時使用螢幕虛擬按鈕
- 飛行：W/S 或 ↑/↓ 俯仰、D/→ 推進、A/← 煞車、Esc 返回工作台
- 設計提示：升力中心(黃點)應位於重心(藍點)稍後方；機翼放在機身下方/後方較穩。

## 已實作

2D 飛行物理(推力、升力、阻力、失速、地面效應、散熱過熱、風、地形碰撞)、5 個關卡(1-1~1-5)與三星、預算、商店解鎖、
首通獎勵與省錢獎金、存檔槽、JSON 藍圖匯入匯出、完整狀態流程。

## 第二輪新增

## 第三輪新增
推進器旋轉/鏡像改變推力方向與力矩（含尾焰方向），力矩由推進器相對重心位置計算。

## 第四輪新增
硬著陸損毀判定（垂直撞擊速度超過 4+0.15×骨架數，上限 8 m/s；骨架越多越耐撞）；★★ 改為「達成時間目標 或 全程無結構損毀」。

## 第五輪新增
互動教程（GDD 第八章）：首次進入 1-1 自動啟動，依玩家實際操作推進（放置骨架/機翼/推進器→連通性紅框→CG/CP→預算與TWR→試飛→推進/拉起/地面效應/過熱/失速）；可略過，主選單「教學」與工作台「❓ 教學」可重看；完成狀態存於 localStorage。

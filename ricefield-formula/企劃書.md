《稻香方程式：空天黎明》
遊戲企劃規格書 GDD v0.2 (Ricefield Formula: Skyward Dawn)
一、遊戲定位
1. 核心概念
《稻香方程式：空天黎明》是一款以 JavaScript 與 HTML5 Canvas 製作的 2D 格點式飛機建造與飛行闖關遊戲。

玩家在充滿稻田、山谷、氣流與研究設施的世界中，利用各種材料和零件自由拼裝飛行器，再親自駕駛它完成任務。

遊戲的主要樂趣來自：

自由創造：像 Minecraft 一樣，以格點為基礎自由放置、拆除和組合零件。
立即試飛：完成建造後，能迅速進入飛行，不需要繁瑣的設定程序。
創意解題：同一關卡可以用不同機體、飛行路線與操作技巧完成。
反覆改良：根據飛行結果調整設計，讓下一次表現更好。
持續成長：解鎖新材料、推進器、機翼與特殊裝置，挑戰更困難的關卡。
設計原則：這是一款好玩的遊戲，而不是要求玩家學會真實航空工程的模擬器。

2. 遊戲類型與平台
類型：2D 建造、物理動作、關卡挑戰、輕度策略。
平台：現代桌面與行動瀏覽器。
技術：HTML、CSS、原生 JavaScript、Canvas 2D。
儲存：localStorage。
第一版不需要帳號、後端或網路連線。
支援鍵盤與觸控操作。
二、核心遊戲循環
玩家反覆經歷以下過程： $$\text{接取任務} \longrightarrow \text{建造飛機} \longrightarrow \text{試飛} \longrightarrow \text{完成挑戰} \longrightarrow \text{獲得獎勵} \longrightarrow \text{解鎖與改良} \longrightarrow \text{挑戰新關卡}$$
獎勵可以用於建造自己的自用飛機，用於pvp或pve挑戰(獨立於關卡外)

建造階段：讓玩家發揮創意，以格點拼裝機體。
試飛階段：讓設計立刻產生直觀的物理與飛行反饋。
任務階段：提供明確目標與地形／氣候操作挑戰。
結算階段：讓玩家清楚知道設計的優點、痛點與改進空間。
成長階段：提供全新組合可能（新零件與藍圖），而非單純堆疊數值。
玩家應能在幾分鐘內完成一次完整的建造與試飛循環。
三、格點式自由建造系統
1. 建造規則
採用類似 Minecraft 的格點式建造。
工作台由可向各方向無限延伸的格點構成。
每個零件占據一個或多個格點。
玩家可放置、拆除;程式需自動旋轉（90°）和鏡像翻轉零件。
連通性檢驗：零件必須透過相鄰格點或指定連接面，與機身核心連成一體。不允許存在未連接到核心的懸空部件。
無人為尺寸上限：機體沒有預先設定的固定寬度、高度或零件數量上限；建造畫面支援平移與縮放，支援打造超大型機體。
內部資料結構：採用稀疏格點（Sparse Grid Map / Hash Table），鍵值為 x,y 字串或雜湊，只儲存實際放置的零件，絕不建立龐大而稀疏的空白二維／三維陣列。
2. 建造操作
桌面操作：
左鍵：放置或選取零件。
右鍵：拆除零件。
滾輪：縮放工作台（Zoom In / Out）。
中鍵拖曳 / Space+左鍵：平移工作台視角。
R 鍵：旋轉零件（90° 順時針）。
F 鍵：水平鏡像翻轉零件。
Ctrl + Z：復原（Undo）。
Ctrl + Y：重做（Redo）。
Space 鍵：快速進入試飛。
行動裝置操作：
零件工具列點擊選取。
點擊格點放置、長按格點拆除。
雙指張合縮放、雙指拖曳平移。
建造期即時儀表：
機體總重量（Total Mass）。
零件總造價（Total Cost）。
推進器總推力（Total Thrust）。
機翼總升力係數（Total Lift Coefficient）。
重心位置（Center of Gravity, CG 標記）。
結構連通狀態檢查（未連接部件標紅警示）。
當前關卡預算使用百分比。
3. 自由度與視覺表現
格點僅用於決定拓撲位置與結構連接，不強制零件呈單一方塊狀。
零件可具備斜翼、流線型機鼻、圓形引擎與弧面防禦板等豐富外形。
四、零件組合與設計深度
1. 零件類別與權衡矩陣
類別	主要作用	關鍵工程權衡
核心與骨架	提供駕駛艙、核心判定與結構連接基礎	重量、造價成本、結構剛性
推進器	提供向前推力與加速	推力大小、自重、發熱率、能量消耗
機翼與控制面	產生氣動升力、控制俯仰姿態	升力係數、空氣阻力、低速/高速適配度
輔助裝置	散熱、額外浮力、重心微調	成本、佔用空間、操作時機
戰鬥與特殊模組	提供電磁干擾、防禦或定向衝擊	重量、耗能、冷卻冷卻時間
2. 避免純數值堆疊的組合流派
大型木翼：低速升力充沛，適合極限低成本滑翔，但高速迎風阻力巨大。
高速後掠翼：高速阻力小、俯衝性能優異，但失速速度高，起飛需長距離加速。
高功率推進器 vs 散熱配置：短時間爆發力驚人，但連續運轉會過熱熄火，需搭配散熱鰭片或改採間歇性點火操作。
骨架強化：大幅降低迫降損壞機率，但額外重量會顯著壓低推重比。
3. 設計分析工具
重心（CG）標記：藍色點標示質量中心。
升力中心（CP）提示：黃色標記標示總升力等效作用點。
推重比（TWR）儀表：提示是否具備平地離地與爬升能力。
失衡預警：及時提示「嚴重頭重（俯衝失控風險）」或「嚴重尾重（失速仰翻風險）」。
五、飛行與物理系統
1. 基本操作
操作	鍵盤按鍵	觸控操作
拉起機頭 / 爬升	W 或 ↑	虛擬搖桿向上 / 左側上推滑塊
壓低機頭 / 俯衝	S 或 ↓	虛擬搖桿向下 / 左側下推滑塊
主動力推進	D 或 →	右側主按鈕：按住推進
減速 / 空氣反推	A 或 ←	右側副按鈕：按住煞車
特殊裝置 / 技能	Space / Q	技能圓鈕點擊
飛行具有物理慣性：關閉油門後飛機依賴動能滑翔，拉起機頭會將前進動能轉換為高度，動能不足時將產生失速下墜。
2. 簡化物理模型
質量加速度：$F_{net} = T - D - W \cdot \sin(\theta)$，依照時間步長（Fixed Delta Time）穩定積分。
氣動升力：$L = 0.5 \cdot \rho \cdot v^2 \cdot S_{wing} \cdot C_L(\alpha)$。
失速機制：當攻角 $\alpha$ 過大且空速低於臨界值時，升力驟降、阻力激增。
地面效應（Ground Effect）——本作招牌機制：
當飛機貼近稻浪低空（離地特定高度以內）時，地面阻擋翼尖渦流，升力提升 30%，誘導阻力降低 40%。
貼地滑翔可實現極致節能與高速突破，但伴隨地形起伏碰撞風險，帶來「速度 vs 風險」的高刺激心流。
六、關卡與挑戰系統
1. 關卡設計節奏
每關只引入 1~2 個新機制，讓玩家在試錯中直觀掌握：

Stage 1-1：稻田試飛
任務：飛越稻田並安全抵達終點。
重點：驗證基礎建造、離地起飛、平穩升力與著陸姿態。
Stage 1-2：橡皮筋挑戰
任務：只能使用指定的低成本推進方式完成飛行。
重點：擺脫大馬力依賴，掌握輕量化減重、動能轉化與滑翔。
Stage 1-3：山谷逆風
任務：穿越高度起伏劇烈的峽谷與強烈陣風。
重點：飛行路線選擇、爬升攻角管理與抗風阻機翼配置。
Stage 1-4：雷達死角
任務：在限定高度以下穿越警戒區。
重點：主動運用「稻浪地面效應」進行極低空掠地突防。
Stage 1-5：長途巡航
任務：通過多段地形與中途檢查點。
重點：散熱熱平衡、能耗管理與整機綜合巡航效率。
2. 三星評級體系
★☆☆ 通關完畢：成功抵達終點線並完成任務。
★★☆ 操作表現：達成指定時間標準或未發生機體嚴重結構損毀。
★★★ 工程挑戰：達成該關限定的**低預算目標（如剩餘預算 $\ge 40%$）**或特殊結構限制。
七、獎勵、解鎖與重玩機制
1. 經濟與進程
首通獎勵：每關首次通關發放豐厚研發資金。
省錢激勵：關卡中節省的預算轉換為額外獎金結算。
零挫折承諾：失敗、墜毀無任何金幣懲罰，零件無耐久損耗與維修冷卻。
重複刷關限制：首通獎勵不可重複刷取，重複挑戰以突破三星紀錄與解鎖新藍圖為目標。
2. 藍圖收藏與管理系統
支援自定義命名與存檔槽位（Slot 1~N）。
支援藍圖複製、修改與另存新檔。
支援標準化 JSON 格式匯入與匯出（可複製文字代碼分享給其他玩家）。
藍圖資料結構包含零件坐標清單、旋轉角度、鏡像狀態與機體版本號。

十一、實作階段路線圖
階段一：稀疏格點建造原型（放置/拆除/旋轉/鏡像/連通性/重心顯示）。
階段二：飛行物理與地面效應手感（推力/升力/俯仰/貼地滑翔/碰撞檢測）。
階段三：首個完整閉環關卡（Stage 1-1 建造 $\rightarrow$ 起飛 $\rightarrow$ 著陸 $\rightarrow$ 結算）。
階段四：首發五大關卡與經濟進程（Stage 1-1 ~ 1-5、三星評價、零件解鎖、藍圖 JSON）。
階段五：視聽打磨與體驗優化（金黃稻浪粒子、尾焰、音效合成、操作回饋細節）。

Rust Suvival 計劃書概述

Rust Suvival 是一款策略生存遊戲，結合資源分配與戰略戰鬥，提供玩家高效沉浸式遊戲體驗。

遊戲特色

  • 高效性能：Galaxy 版本優化遊戲流暢度
  • 沉浸體驗：Galaxy-Max 加入更多視覺特效
  • 特別活動：Happy Birthday 特別釋出版本祝羽彤生日快樂！！！

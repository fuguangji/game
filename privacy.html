隱私權政策

最後更新：2026 年 11 月 8 日

本政策適用於光風濟月共用帳號中心，以及使用該帳號登入的遊戲服務（以下合稱「本服務」）。本政策說明本服務蒐集、處理、利用及保護個人資料的方式。個別遊戲若有額外資料處理方式，會另行告知。

一、服務資訊與聯絡方式

  • 服務名稱：光風濟月 GAMES／Hanexo 共用帳號中心。
  • 資料請求及服務聯絡方式：sky.breaded.4g@icloud.com。

如所在地法律要求提供資料控制者的法定身分、地址或其他資訊，相關資訊應依適用法律提供。本頁列出的服務名稱及聯絡方式，不取代任何法定揭露義務。

二、蒐集的資料類別

  • 帳號與識別資料：註冊及登入使用的電子郵件、Firebase 使用者識別碼（UID）、顯示名稱，以及 Firebase 帳號提供的電子郵件驗證狀態等資料。
  • 帳號設定與金鑰中繼資料：個人檔案中的建立／更新時間，以及支援加密功能所需的 KDF 版本、salt、加密金鑰封裝密文、IV、公鑰及 key ID 等中繼資料。這些欄位不等同於登入密碼。
  • 遊戲與存檔資料：遊戲進度、設定、玩家資料及雲端存檔。不同遊戲可能處理不同欄位，實際內容取決於使用的遊戲功能。
  • 服務安全與技術資料：驗證請求、API 請求及錯誤處理所需的技術資訊。Firebase、Render 等服務供應商也可能依其服務運作產生連線、診斷、安全或系統紀錄。
  • 瀏覽器端登入狀態：Firebase Authentication 使用瀏覽器本機持續性機制保存登入狀態，以便同一網站來源的支援頁面延續登入；這不應被理解為本服務自行建立一般追蹤 Cookie。

電子郵件與帳號識別資料是註冊及登入所必需；未提供時，將無法建立帳號或使用需登入的功能。其他資料依實際使用的功能而定。

三、蒐集目的與使用方式

資料用於建立及驗證帳號、共用登入狀態、提供玩家個人檔案與雲端存檔、保存遊戲功能所需設定、維護系統安全、排除故障、處理使用者請求，以及履行法律義務。資料僅在達成上述目的所必要的範圍內處理。

電子郵件與密碼由 Firebase Authentication 處理；依目前程式設計，帳號密碼不會傳送至 Render 遊戲 API。Render API 會驗證 Firebase ID token，並以帳號 UID 取得或處理對應的伺服器端資料。

四、存檔加密與資料安全說明

不同存檔欄位採取不同處理方式，並非所有雲端存檔均為端對端加密：

  • 一般存檔資料：目前伺服器程式會將一般存檔欄位直接寫入 Firestore，並非全部先經用戶端加密。
  • 敏感資料封裝：支援加密的敏感資料會以密文封裝欄位儲存；相關金鑰中繼資料另存於帳號資料中。
  • 傳輸及存取：服務使用 HTTPS 等加密傳輸方式、Firebase ID token 驗證及伺服器端存取控制等措施。Firestore 的瀏覽器端直接存取受到規則限制，伺服器端則透過受控服務存取。

網路傳輸、雲端服務及電子儲存均無法保證絕對安全。請勿將密碼、驗證碼或其他不應公開的資訊放入遊戲名稱、公開內容或一般存檔欄位。

五、第三方服務及資料跨境處理

  • Google Firebase：用於帳號驗證及 Firestore 雲端資料服務。Firebase 可能依其服務條款及隱私權政策處理必要資料。
  • Render：用於託管遊戲 API；API 會驗證 Firebase 身分並處理相應的遊戲資料。

本網站使用瀏覽器及裝置提供的系統字型，不會為載入字型而直接連線至 Google Fonts 或其他外部字型 CDN。這可減少字型載入時額外傳送連線資訊給字型供應商的情形。

Firebase、Render 等供應商可能在臺灣以外的地區處理或儲存資料；實際位置依各供應商的專案設定、服務架構及政策而定。

除提供本服務、維護安全、處理使用者請求、遵守法律要求或取得適當同意所必要外，帳號資料不會任意出售或提供給無關第三方。

六、資料保存期間

帳號及遊戲資料原則上於提供服務及達成蒐集目的所必要期間保存；當目的消失、帳號終止或提出合法刪除請求時，依適用法律及實際系統能力處理。安全紀錄、供應商備份及系統備援資料可能依各供應商的保存與輪替政策保留一段期間。

目前尚未提供完整的自助刪除帳號功能。你可以透過上述聯絡信箱提出帳號及相關資料刪除請求。帳號資料與關聯資料可能分別儲存在 Firebase／Firestore、Render 及其備份系統；提出請求不代表資料已立即刪除，實際完成時間會依資料所在服務的處理及備份輪替情形而定。

七、你的個人資料權利

依適用的個人資料保護法令，你可以透過聯絡信箱提出以下請求：

  • 查詢或請求閱覽個人資料。
  • 請求製給個人資料複製本。
  • 請求補充或更正不正確的資料。
  • 在法定條件下請求停止蒐集、處理或利用。
  • 在法定條件下請求刪除個人資料。

為避免他人冒用身分，提出請求時可能需要提供合理的帳號驗證資訊。依法得拒絕或限制請求的情形，依適用法律處理並說明理由。請勿寄送密碼或驗證碼。

八、帳號管理方式

你可以在共用帳號中心登出，以結束目前瀏覽器中的登入狀態；登出不會自動刪除已保存於雲端的帳號或遊戲資料。若不再使用本服務，請另行提出資料查詢或刪除請求。

九、未成年人使用

本服務僅適用於年滿 13 歲的使用者。未滿 18 歲者，請先由法定代理人或監護人閱讀本政策並同意後，再註冊及使用本服務。所在地法律對兒童個人資料處理或家長同意另有要求時，依該法律辦理。法定代理人如需查詢或管理未成年使用者的個人資料，可透過上述聯絡方式提出。

十、政策更新

本政策可能因服務功能、供應商或法令變更而更新。更新版本及日期會公布於本頁；若變更涉及重要資料處理方式，會在合理可行範圍內以服務公告或其他適當方式提醒使用者。

隱私權政策

最後更新：2026 年 11 月 8 日

本政策適用於光風濟月共用帳號中心，以及使用該帳號登入的遊戲服務（以下合稱「本服務」）。本政策說明本服務如何蒐集、處理、利用及保護個人資料。個別遊戲若有額外資料處理方式，會另行告知。

營運者資訊待確認：本服務的法定營運者／個人資料蒐集者名稱及其身分，目前尚未在專案資料中確認。正式公開本政策前，必須補上實際負責營運者的姓名或依法應揭露的組織名稱；「光風濟月」為服務／品牌名稱，不應在未確認前直接視為法定主體。

一、蒐集者與聯絡方式

  • 服務名稱：光風濟月 GAMES／Hanexo 共用帳號中心。
  • 個人資料蒐集者／營運者：待營運者確認後填入正式名稱。
  • 隱私及資料請求聯絡方式：sky.breaded.4g@icloud.com。

二、蒐集的資料類別

  • 帳號與識別資料：註冊及登入使用的電子郵件、Firebase 使用者識別碼（UID）、顯示名稱，以及 Firebase 帳號提供的電子郵件驗證狀態等資料。
  • 帳號設定與金鑰中繼資料：個人檔案中的建立／更新時間，以及支援加密功能所需的 KDF 版本、salt、加密金鑰封裝密文、IV、公鑰及 key ID 等中繼資料。這些欄位不等同於你的登入密碼。
  • 遊戲與存檔資料：遊戲進度、設定、玩家資料及雲端存檔。不同遊戲可能處理不同欄位，實際內容取決於你使用的遊戲功能。
  • 服務安全與技術資料：驗證請求、API 請求及錯誤處理所需的技術資訊。Firebase、Render 等供應商也可能依其服務運作產生連線、診斷、安全或系統紀錄。
  • 瀏覽器端登入狀態：Firebase Authentication 使用瀏覽器本機持續性機制保存登入狀態，以便同一網站來源的頁面延續登入；這不應被理解為本服務自行建立一般追蹤 Cookie。

三、蒐集目的與使用方式

資料用於建立及驗證帳號、共用登入狀態、提供玩家個人檔案與雲端存檔、保存遊戲功能所需設定、維護系統安全、排除故障、處理使用者請求，以及履行法律義務。資料會在達成上述目的所必要的範圍內處理，不會任意改作無關用途。

電子郵件與密碼由 Firebase Authentication 處理；依目前程式設計，帳號密碼不會傳送至本專案的 Render 遊戲 API。Render API 會驗證 Firebase ID token，並以帳號 UID 取得或處理對應的伺服器端資料。

四、存檔加密與資料安全說明

本服務的不同存檔欄位採取不同處理方式，不能將所有雲端存檔一概描述為端對端加密：

  • 一般存檔資料：目前伺服器程式會將一般存檔欄位直接寫入 Firestore，並非由本政策保證全部先經用戶端加密。
  • 敏感資料封裝：支援加密的敏感資料會以密文封裝欄位儲存；相關金鑰中繼資料另存於帳號資料中。
  • 傳輸及存取：服務使用 HTTPS 等加密傳輸方式、Firebase ID token 驗證及伺服器端存取控制等措施。Firestore 的瀏覽器端直接存取受到規則限制，伺服器端則透過受控服務存取。

我們會依服務規模採取合理的安全措施，但網路傳輸、雲端服務及電子儲存均無法保證絕對安全。請勿將密碼、驗證碼或其他不應公開的資訊放入遊戲名稱、公開內容或一般存檔欄位。

五、第三方服務及資料跨境處理

  • Google Firebase：用於帳號驗證及 Firestore 雲端資料服務。Firebase 可能依其服務條款及隱私權政策處理必要資料。
  • Render：用於託管遊戲 API；API 會驗證 Firebase 身分並處理相應的遊戲資料。
  • Google Fonts：本政策頁面載入 Google Fonts 字型。瀏覽器連線至 Google 字型服務時，Google 可能取得提供該資源所需的連線資訊。

上述供應商可能在臺灣以外的地區處理或儲存資料；實際資料中心位置依各供應商的專案設定、服務架構及政策而定。本專案目前未能從程式碼確認 Firebase／Firestore 與 Render 的實際部署地區，因此不在此宣稱特定國家或地區。

除提供本服務、維護安全、處理使用者請求、遵守法律要求或取得你同意所必要外，本服務不會任意出售或提供可識別你的帳號資料給無關第三方。

六、資料保存期間

帳號及遊戲資料原則上於提供服務及達成蒐集目的所必要期間保存；當目的消失、帳號終止或你提出合法刪除請求時，會依適用法律及實際系統能力處理。安全紀錄、供應商備份及系統備援資料可能依各供應商的保存與輪替政策保留一段期間。

目前本服務尚未提供完整的自助刪除帳號功能，且伺服器端尚無可由使用者自行觸發、一次清除帳號與其關聯資料的完整流程。你可以透過本政策所列信箱提出請求；在刪除流程完成並經確認前，不應將提出請求視為資料已經刪除。正式上線前，營運者仍須確認並建立可執行的帳號及資料刪除作業。

七、你的個人資料權利

依適用的個人資料保護法令，你可以透過聯絡信箱提出以下請求：

  • 查詢或請求閱覽你的個人資料。
  • 請求製給個人資料複製本。
  • 請求補充或更正不正確的資料。
  • 在法定條件下請求停止蒐集、處理或利用。
  • 在法定條件下請求刪除個人資料。

為避免他人冒用你的身分，我們可能要求提供合理的帳號驗證資訊。依法得拒絕或限制請求的情形，將依適用法律處理並說明理由。提出請求時，請勿寄送密碼或驗證碼。

八、你可以如何管理帳號

你可以在共用帳號中心登出，以結束目前瀏覽器中的登入狀態；登出不會自動刪除已保存於雲端的帳號或遊戲資料。若你不再使用本服務，請另行提出資料查詢或刪除請求。

九、未成年人使用

若你尚未具備依適用法律獨立同意個人資料處理的資格，請在法定代理人或監護人了解本政策並依法同意後使用涉及個人資料的功能。法定代理人如對未成年人的資料有疑問，可透過上述聯絡方式提出。

十、政策更新

本政策可能因服務功能、供應商或法令變更而更新。更新版本及日期會公布於本頁；若變更涉及重要資料處理方式，會在合理可行範圍內以服務公告或其他適當方式提醒使用者。

隱私權政策

最後更新：2026 年 11 月 8 日

本政策說明光風濟月共用帳號中心，以及使用該帳號登入之遊戲服務，如何處理與保護你的資料。個別遊戲如有額外資料處理方式，會在該遊戲另行說明。

我們處理哪些資料

  • 帳號資料：註冊或登入所需的電子郵件、Firebase 使用者識別碼，以及你提供的顯示名稱。
  • 遊戲資料：為提供遊戲功能而處理的玩家個人檔案、雲端存檔及加密金鑰中繼資料。存檔可能包含你的遊戲進度與設定；支援加密的存檔會以密文形式儲存。
  • 服務與安全資料：登入狀態、驗證所需的識別憑證，以及服務供應商在提供、維護和保護服務時可能產生的技術紀錄。

資料用途與帳號驗證

我們使用上述資料建立及驗證帳號、在支援的遊戲間共用登入狀態、提供個人檔案與雲端存檔功能、維護服務安全，以及處理你提出的問題。Firebase Authentication 直接處理電子郵件與密碼驗證；密碼不會傳送至本專案的遊戲 API。登入狀態會依 Firebase 的瀏覽器本機持續性設定保存在你的瀏覽器中。

服務供應商與資料分享

為提供服務，資料可能由 Firebase（帳號驗證及相關雲端資料服務）與 Render（遊戲 API 託管）等服務供應商依其服務條款及隱私權政策處理。遊戲 API 會在驗證帳號後，以帳號識別碼處理相應的個人檔案或存檔。我們不會因本政策而將你的資料出售給他人；除提供服務、維護安全、遵守法律要求或取得你同意所必要外，不會任意提供你的帳號資料。

保存與安全

資料會在提供帳號及遊戲功能所需期間保存。服務使用傳輸加密及存取控制等措施保護資料；支援加密的雲端存檔會以密文儲存。不過，網際網路傳輸及電子儲存方式都無法保證絕對安全。

你的選擇與聯絡方式

你可以停止使用服務並從共用帳號中心登出。如需詢問資料、提出更正或刪除請求，請透過反映管道聯絡我們；請勿在公開留言中張貼密碼、驗證碼或其他敏感資料。

政策變更

我們可能因服務或法規變更更新本政策。更新版本會發布於本頁，並更新頁面所列日期。繼續使用相關服務前，請留意政策內容。

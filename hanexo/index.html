INDUSTRIAL STRATEGY / PROJECT 001

HANEXOSystems in motion. Every unit matters.

一個由工業、能源、物流與軍事系統交織而成的策略模擬企劃。從一個單位開始，讓每條產線、每份資源與每個決策彼此連結，逐步構築能夠運作的整體。

SYSTEM MAP / CONCEPTUAL
01 / DESIGN PHILOSOPHY

不是堆疊單位，
而是讓系統彼此運作。

HANEXO 的重點不只在單一建築或單位有多強，而在它們如何透過生產、能源、補給與指揮形成完整網路。

PRINCIPLE / 01

每個單位都有位置

系統由許多可理解、可組合的單位構成。缺少其中一環，整體可能就無法順利運作。

PRINCIPLE / 02

連結帶來能力

生產不等於完成。資源必須能運輸，能源必須能供應，指令也必須抵達真正執行它的單位。

PRINCIPLE / 03

策略來自取捨

擴張、維持、研究與防衛都會消耗有限資源。如何分配與安排優先順序，是策略的一部分。

02 / SYSTEM ARCHITECTURE

一張互相依賴的網。

以下是目前的核心設計方向，而非已完成或已實裝的功能清單。

01

生產與工業

採集原料、加工資源、建立產線，讓各個單位有能力持續運作。

02

能源網路

能源生產與需求需要互相匹配；供應不足會限制整體系統的運作。

03

物流與補給

資源需要抵達正確的位置。產能、運輸距離與路線安排都可能影響效率。

04

指揮與單位

把命令、行動單位與支援設施連接起來，讓戰術選擇建立在整體部署之上。

05

防衛與戰略

防禦、部署與資源調度共同影響安全。軍事能力不是脫離工業系統的獨立數值。

06

多人協作

企劃方向包含單人與多人玩法的探索；連線方式、房間管理與權威模型仍需逐步驗證。

03 / SYSTEM LOOP

從原料，到行動。

這個概念流程展示 HANEXO 希望建立的系統關係：各環節互相依賴，而不是彼此孤立。

04 / DEVELOPMENT DIRECTION

先讓核心系統成立。

開發路線以可驗證的小型原型為起點；具體順序會隨測試結果調整。

PHASE 01 / FOUNDATION

核心模擬與畫面

釐清單位、資源與模擬邏輯，建立輕量的 2D 俯視角原型，讓遊戲規則可以獨立測試。

PHASE 02 / CONNECTIONS

系統互相連結

逐步加入生產、能源、物流與指揮之間的關係，測試規則能否形成有意義的策略選擇。

PHASE 03 / MULTIPLAYER

連線與同步探索

在單機核心穩定後，再驗證多人房間、狀態同步與主機中斷等問題。
